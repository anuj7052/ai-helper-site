A little help for your helper.

Setup, troubleshooting, and support for AI Helper on desktop Chrome and Edge.

Getting started

  1. Install from the public store listing once available. Store launch is currently in preparation.
  2. Open AI Helper → Settings. Run the browser self-test if you want to check page access without an API key.
  3. Enter an OpenAI-compatible API base URL, a tool-calling model, and your own API key.
  4. Read and accept the data-sharing disclosure, test the connection, then save.
  5. Return to Overview, describe a task, and click “Let’s do it”. Review progress from the task log.

Common questions

Do I need an API key?

Yes, for cloud AI providers. A ChatGPT subscription does not include API credits. Local OpenAI-compatible servers may work without a key if they support tool calling. Provider charges are separate from the extension.

Why did my settings disappear?

API keys, settings, and history use session memory. Re-enter them after restarting the browser or reloading/updating the extension.

The connection test fails

Check that the base URL ends before /chat/completions, the API key is valid, the account has quota, and the model supports function/tool calling. A 401 generally indicates credentials; a 429 may indicate quota or rate limits. Never post your key in a support issue.

A page action fails

Check extension site permissions. Password fields, file uploads, CAPTCHAs, protected browser pages, cross-origin frames, and some complex controls require manual interaction. Start with a smaller task and inspect the action log.

How can I stop or delete a task?

Open the task and choose Stop task, or close its workspace window. Clear history from Task history. Clear all session settings, keys, and history from Settings → Clear session data. This does not undo changes on websites or delete data from your AI provider.

Does it work on phones?

This release targets desktop Chrome/Edge 124+ on macOS and Windows. Mobile Chrome cannot install desktop extensions.

Report a problem or request a feature

Include the extension version, OS, browser version, and a short description with steps to reproduce. Redact personal information from screenshots. Reports are public.
