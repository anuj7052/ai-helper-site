A little help for your helper.

Setup, troubleshooting, and support for AI Helper on desktop Chrome and Edge.

Getting started with Copilot

  1. Install the development extension on desktop Chrome/Edge. Public store launch is still in preparation.
  2. Install Node.js 22+, extract the project/companion package, and run npm ci, then npm run companion.
  3. In Settings, pair using the code printed by the terminal. Keep the companion running.
  4. Click Connect GitHub Copilot. Open GitHub authorization, sign in, and enter the displayed device code.
  5. Return, refresh models, choose GitHub Copilot and an available model, accept the data-sharing disclosure, test, and save.
  6. Optionally enable Advanced browser control and grant debugging permission for screenshots and real input.
  7. Run a simple task on example.com, then review its log. Pause/Resume and Stop are available in task details.

For local sign-out use “Sign out of companion Copilot”. Stop/restart the companion after configuration changes. Removing all companion files requires deleting its printed data directory after stopping it. This does not revoke GitHub authorization; manage that separately in GitHub settings.

Common questions

Do I need an API key?

Not for GitHub Copilot mode: authorize using GitHub device login through the local companion. Your account needs Copilot access, model enablement, and quota. Other custom cloud API connections still need their own keys. No AI credits are bundled.

Why did my settings disappear?

Browser settings, history, and pairing tokens use session memory. Pair again and save the connection after restarting/reloading. The companion’s separate GitHub authorization normally persists locally.

The connection test fails

Confirm the companion is running, pair again after it restarts, complete GitHub authorization, and refresh models. Check Copilot account/organization policies and quota. For custom APIs, verify the base URL, key, and tool-calling model. Never post keys or pairing codes in support issues.

A page action fails

Check site permissions and the Advanced browser control setting. Screenshots require a vision-capable model. Closing Chrome’s debugging notice stops the task. Browser-protected pages, OS dialogs, passwords, file uploads, CAPTCHAs, and some complex controls require manual work.

How can I stop or delete a task?

Pause at an action boundary, Stop, or close the workspace. Clear session data in Settings to remove browser records. This does not undo website changes, erase companion files, or delete provider records.

Does it work on phones?

This release targets desktop Chrome/Edge 124+ on macOS and Windows. Mobile Chrome cannot install desktop extensions.

Report a problem or request a feature

Include the extension version, OS, browser version, and a short description with steps to reproduce. Redact personal information from screenshots. Reports are public.
