Privacy policy

Updated October 15, 2026 · Applies to AI Helper version 0.4.0

AI Helper is a browser task assistant maintained by Anuj Singh (GitHub: anuj7052). This policy explains the extension, optional local companion, and public website.

GitHub Copilot companion and advanced mode

Copilot mode sends your task conversation and browser observations to a paired local companion at 127.0.0.1:4317. The companion uses an isolated OpenCode runtime to authorize your GitHub.com account through GitHub’s device-code flow and request actions from your selected Copilot model. GitHub credentials stay in the companion’s local OpenCode profile, not in the extension. The extension stores a separate local pairing token in session memory. Your GitHub privacy policy, Copilot plan, organization settings, and provider retention rules apply.

Advanced browser control uses optional debugger permission for trusted input and viewport screenshots on task-owned pages. When requested by the agent, screenshots are sent as image data to the next model request and may contain visible personal or sensitive information. They are not saved in extension task history. The model must support images. Chrome/Edge shows a debugging notice while attached. No arbitrary model-generated JavaScript or protocol commands are executed.

The companion stores authorization and OpenCode databases under ~/.ai-helper (Windows: %USERPROFILE%\.ai-helper), unless you set AI_HELPER_HOME. It attempts to abort/delete each planning session after completion or cancellation, but local databases/logs or interrupted processes may retain traces. AI Helper does not implement OS-keychain encryption for these files. Sign out using “Sign out of companion Copilot”; to delete all companion data, stop it and delete its printed data directory. Browser “Clear session data” does not delete companion files. Revoke GitHub authorization separately in your GitHub settings if needed. The companion uses its own profile and does not import existing OpenCode credentials.

The extension does not read your browser’s history database or export cookies, collect advertising identifiers, or run analytics. It does not read password input values or upload local files. Website text can nevertheless include sensitive information; only use tasks and pages you intend to send to your chosen provider.

When data is transmitted

You must accept the in-product disclosure before saving an AI connection or testing the provider. Starting a task sends the task and workspace observations through your selected connection. “Test connection” sends a small test prompt through Copilot or your custom endpoint; custom API mode also sends its authorization key. Pairing and GitHub sign-in contact the local companion and GitHub before task data is sent. “Browser self-test” opens example.com and reads its heading locally without contacting AI.

The extension can interact with logged-in website sessions. Actions may submit information to websites under their own policies. Pause takes effect at action boundaries; Stop prevents further actions but cannot undo dispatched actions. Moving a task tab outside its workspace makes it ineligible for further actions.

Sharing and service providers

Copilot requests go through your local OpenCode companion to GitHub Copilot. Custom API requests go directly from the browser to your configured endpoint. The developer does not operate an intermediary server and does not receive your task content, authorization, or observations. Provider privacy policies, retention terms, processing locations, and account settings govern data received. If you use OpenAI, consult OpenAI’s privacy policy.

AI Helper does not sell user data or use or transfer it for advertising, creditworthiness, or lending decisions. Data is used only for the user-requested task and visible features. The developer does not routinely have human access to extension task data.

Storage, security, and retention

API keys, settings, consent, and task history are kept in Chrome/Edge extension session storage, which is in memory and restricted to trusted extension contexts. They are not synced or intentionally persisted to disk by the extension. They clear when the browser restarts or the extension is disabled, reloaded, updated, or uninstalled. Provider requests require HTTPS, except local connections to localhost on your own computer. Remote JavaScript supplied by an AI model is never executed; only packaged, enumerated actions are supported.

Website task tabs remain open until you close them, and normal browser history and website storage can remain under your browser’s own settings. Older development versions stored settings/history locally; version 0.3.0 removes those legacy records on worker startup. Your chosen provider may retain requests according to its own terms.

Your controls and deletion

  • Use Stop task to cancel the model request and prevent further actions.
  • Use Task history → Clear history to delete session task records when no task is running.
  • Use Settings → Clear session data to remove settings, API key, consent, and history.
  • Change the endpoint and accept the disclosure again to use a different provider.
  • Remove the extension or revoke its website access through your browser’s extension settings.
  • Contact your AI provider to request deletion of data it has already received. Clearing AI Helper does not delete provider records or undo changes made on websites.

This website and support

This website is hosted on GitHub Pages. GitHub may receive technical request data, such as IP addresses and request logs, under the GitHub privacy statement. This site sets no custom cookies and includes no analytics or advertising scripts. Support is provided through GitHub Issues. Issues are public: do not include API keys, private task content, or personal documents. Information you voluntarily post is visible to GitHub users and is used to answer your request.

Limited Use

AI Helper’s use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is handled only to provide the extension’s disclosed, user-facing browser-task functionality.

Changes and contact

Changes will be posted on this page with an updated date. For questions, corrections, or privacy requests, use the support page. Avoid including sensitive data in public reports.
