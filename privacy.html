Privacy policy

Updated October 15, 2026 · Applies to AI Helper version 0.5.0

AI Helper is a browser task assistant maintained by Anuj Singh (GitHub: anuj7052). This policy explains the extension, optional local companion, and public website.

Subscription choices and side-panel workspaces

Supported subscription connections are GitHub Copilot, Copilot using a user-specified GitHub Enterprise hostname, and eligible ChatGPT/Codex subscriptions through OpenCode. The companion initiates device authorization with the selected provider; a custom Enterprise hostname is passed to OpenCode to select that organization’s OAuth and Copilot service endpoints. OpenAI authorization uses auth.openai.com. Tasks and screenshots in ChatGPT mode are sent through the companion to OpenAI’s ChatGPT/Codex service, under OpenAI’s privacy policy. Enterprise organization policies also apply. No provider credentials are copied into the extension.

The sidePanel permission keeps the agent UI beside your pages. Tasks started there create their own tabs in the current window; the agent does not adopt unrelated existing tabs. Full-dashboard tasks use a separate window. The selected provider gets only task observations collected for that task. The same session-memory and companion-retention controls below apply to each subscription. “Sign out of selected subscription” removes that provider’s local authorization; it does not sign out other connected providers.

Local companion and advanced mode

Subscription mode sends task conversations and observations to a paired companion at 127.0.0.1:4317. Its isolated OpenCode runtime manages device authorization and model requests. Provider credentials stay in its local profile; the extension stores a separate pairing token in session memory. Your provider privacy policy, plan, organization settings, and retention rules apply, including the GitHub privacy policy for Copilot.

Advanced browser control uses optional debugger permission for trusted input and screenshots on task-owned pages. Requested screenshots go to the next model request and may contain visible sensitive information. They are not saved in extension task history. A vision-capable model is required. Chrome/Edge shows a debugging notice. No arbitrary model-generated JavaScript or protocol commands are executed.

Companion authorization and OpenCode databases are stored under ~/.ai-helper (Windows: %USERPROFILE%\.ai-helper), unless AI_HELPER_HOME overrides it. Planning sessions are logically deleted after cleanup attempts, but databases/logs or interrupted processes may retain traces. AI Helper does not implement OS-keychain encryption for these files. Use “Sign out of selected subscription” to remove its credential. To delete all companion data, stop it and delete its printed directory. Browser “Clear session data” does not delete companion files. Revoke authorization separately in the provider’s settings. Existing OpenCode credentials are not imported.

Website text can nevertheless include sensitive information; only use tasks and pages you intend to send to your chosen provider.

When data is transmitted

You must accept the in-product disclosure before saving an AI connection or testing the provider. Starting a task sends the task and workspace observations through your selected connection. “Test connection” sends a small test prompt through Copilot or your custom endpoint; custom API mode also sends its authorization key. Pairing and GitHub sign-in contact the local companion and GitHub before task data is sent. “Browser self-test” opens example.com and reads its heading locally without contacting AI.

The extension can interact with logged-in website sessions. Actions may submit information to websites under their own policies. Pause takes effect at action boundaries; Stop prevents further actions but cannot undo dispatched actions. Moving a task tab outside its workspace makes it ineligible for further actions.

Sharing and service providers

Subscription requests go through your local OpenCode companion to the selected GitHub Copilot/Enterprise or OpenAI ChatGPT/Codex service. Custom API requests go directly to your configured endpoint. The developer does not operate an intermediary server and does not receive task content, authorization, or observations. Provider privacy policies, retention terms, processing locations, and account settings govern received data. Consult OpenAI’s privacy policy for ChatGPT/OpenAI processing.

AI Helper does not sell user data or use or transfer it for advertising, creditworthiness, or lending decisions. Data is used only for user-requested tasks and visible features. The developer does not routinely have human access to extension task data.

Storage, security, and retention

API keys, settings, consent, and task history are kept in Chrome/Edge extension session storage, which is in memory and restricted to trusted extension contexts. They are not synced or intentionally persisted to disk by the extension. They clear when the browser restarts or the extension is disabled, reloaded, updated, or uninstalled. Provider requests require HTTPS, except local connections to localhost on your own computer. Remote JavaScript supplied by an AI model is never executed; only packaged, enumerated actions are supported.

Website task tabs remain open until you close them, and normal browser history and website storage can remain under your browser’s own settings. Older development versions stored settings/history locally; version 0.3.0 removes those legacy records on worker startup. Your chosen provider may retain requests according to its own terms.

Your controls and deletion

  • Use Stop task to cancel the model request and prevent further actions.
  • Use Task history → Clear history to delete session task records when no task is running.
  • Use Settings → Clear session data to remove settings, API key, consent, and history.
  • Change the endpoint and accept the disclosure again to use a different provider.
  • Remove the extension or revoke its website access through your browser’s extension settings.
  • Contact your AI provider to request deletion of data it has already received. Clearing AI Helper does not delete provider records or undo changes made on websites.

This website and support

This website is hosted on GitHub Pages. GitHub may receive technical request data, such as IP addresses and request logs, under the GitHub privacy statement. This site sets no custom cookies and includes no analytics or advertising scripts. Support is provided through GitHub Issues. Issues are public: do not include API keys, private task content, or personal documents. Information you voluntarily post is visible to GitHub users and is used to answer your request.

Limited Use

AI Helper’s use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is handled only to provide the extension’s disclosed, user-facing browser-task functionality.

Changes and contact

Changes will be posted on this page with an updated date. For questions, corrections, or privacy requests, use the support page. Avoid including sensitive data in public reports.
