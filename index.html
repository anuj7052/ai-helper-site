How it works

  1. Install the extension and run its companion with Node.js 22+ on Mac or Windows.
  2. Pair locally, authorize on GitHub, select an available model, and accept the data-sharing disclosure.
  3. Describe a task, watch the steps, and review the result.

GitHub.com Copilot access is required for Copilot mode. Organization policies, model enablement, and usage limits apply. Custom API connections remain available. This is an independent project, not affiliated with GitHub, OpenCode, or Ego Browser.

Built around your browser workspace

Task text, page observations, and requested screenshots go through your local companion to Copilot, or to your selected custom API endpoint. Browser settings and task history use session memory. The companion separately stores its OpenCode authorization and may retain local logs/database traces. There is no developer-operated AI backend, analytics, or advertising.

AI Helper can open/read pages, click, fill, select, scroll, navigate, inspect task popups, and close task tabs. Advanced mode adds screenshots and real input. Browser-protected pages, OS dialogs, passwords, file uploads, CAPTCHAs, and some complex controls need manual interaction. Task success depends on the model and website; it cannot control your whole computer.
