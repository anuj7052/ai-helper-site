How it works

  1. Install AI Helper from its store listing once available.
  2. Read the data-sharing disclosure and connect your API endpoint and model.
  3. Describe a task, watch the steps, and review the answer and source URLs.

A ChatGPT subscription does not include API access. This version does not include a bundled AI service.

Built around your browser session

The extension sends task text and workspace page observations directly to the AI endpoint you select. Your API key and task history stay in extension session memory and clear when the browser restarts or the extension reloads. There is no developer-operated AI backend, analytics, or advertising.

AI Helper can open and read pages, click, fill text fields, select options, scroll, and navigate back. Browser-protected pages, passwords, file uploads, CAPTCHAs, and some complex website controls require manual interaction. Task success depends on the model and website. It cannot control your whole computer.
