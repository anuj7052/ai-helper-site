How it works

  1. Install AI Helper and open its side panel. Choose API-key setup or subscription sign-in.
  2. For subscriptions, run the separate Node.js/OpenCode companion, pair locally, and authorize on GitHub or OpenAI. API mode needs no companion.
  3. Select an available model, accept the disclosure, then describe a browser task.

Organization-managed Copilot accounts on github.com use normal GitHub sign-in; custom Enterprise domains have a separate field. A GitHub Enterprise license alone does not include Copilot. ChatGPT mode exposes eligible Codex models, not every website model. Provider plans, administrator policies, and usage limits apply. This project is not affiliated with Microsoft, GitHub, OpenAI, OpenCode, or Ego Browser.

Built around your browser workspace

Task text, page observations, and requested screenshots go through your local companion to the selected Copilot/Enterprise or ChatGPT service, or to your custom API endpoint. Browser settings and task history use session memory. The companion stores provider authorizations and may retain logs/database traces. There is no developer-operated AI backend, analytics, or advertising.

AI Helper can open/read pages, click, fill, select, scroll, navigate, inspect task popups, and close task tabs. Advanced mode adds screenshots and real input. Browser-protected pages, OS dialogs, passwords, file uploads, CAPTCHAs, and some complex controls need manual interaction. Task success depends on the model and website; it cannot control your whole computer.
